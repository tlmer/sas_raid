## 1. 定位与范围

RAID 层 = **硬件 RAID 加速器**（无固件 CPU ✗）：对 Host 呈现**单个虚拟卷**，把命令条带化
分发到成员盘；RAID 数学（XOR / GF(2⁸)）由硬件引擎完成；成员盘对 Guest **不可见** ✓。

```
                 vdisk_read / vdisk_write（虚拟盘面 = 上层/HBA 命令引擎调用 ✓）
                                │
        ┌───────────────────────▼────────────────────────┐
        │  SasRaidTlm（本模型）                            │
        │  卷表 4 卷×16 盘 │ 条带翻译(§3 五式) │ 等级处理器  │
        │  R0 / R1 / R5(RMW+全条带) / R6(P+Q) / R10      │
        │  GF(2⁸) 引擎(0x11D ✓) │ 降级重建 │ 重建扫描 │ 写洞日志│
        └───────────────────────┬────────────────────────┘
                                │  backend_read / backend_write（**函数指针 ✓ 可绑**）
        ┌───────────────────────▼────────────────────────┐
        │ 成员后端（两种绑定 ✓）                            │
        │  · 单元台：内存阵列（tb_raid_* ✓）               │
        │  · 联合台：**帧级全栈**（tb_raid_array ✓）        │
        │      HBA TLM → link → HDD TLM ×N（复用现工程 ✓） │
        └─────────────────────────────────────────────────┘
```

**分层解耦 ✓**：本模型**不直接依赖** HBA/HDD 模型 —— 成员后端 = `bool (*)(void*, vol, drv,
lba, buf, nblk)` 两枚函数指针 ✓ ⇒ 单元台可绑内存 ✓、联合台可绑真帧级栈 ✓（两类台各自例化 ✓）。

| 面 | 接口 | 说明 |

## 3. 条带几何与地址翻译（spec 五式 ✓ 逐位固化）

```
行（stripe row）字节 = STRIPE_SIZE × nd     nd：R0=n / R1=1 / R5=n-1 / R6=n-2 / R10=n/2
stripe   = (LBA×512) / 行字节
offset   = (LBA×512) % 行字节
drive    = offset / STRIPE_SIZE            ← **条带内数据盘序** ✓
p_drive  = (n-1) - (stripe % n)            ← left-asymmetric 旋转 ✓（R6 的 Q：p1=(n-2)-((stripe+1)%n) ✓）
drive_lba= (stripe×STRIPE_SIZE + offset%STRIPE_SIZE) / 512
```

- 物理盘落位 = 跳过校验盘后按数据序映射（`raid_phys_drive_r5` ✓ / R6 跳两枚 ✓ / R10 对号 ✓）。
- **⚠ 文档勘误**：`规格文档:957-961` 例题行算术自相矛盾 ✗（`(0x1000×512)/(65536×3)` 实算
  = **10** 非 0 ✓）—— 公式本身正确 ✓，实现与判据一律以**公式 + 手算**为准 ✓（见对拍报告）。

## 4. 等级语义（全部与独立参考模型逐字节对拍 ✓）

| 等级 | 读 | 写 | 降级 |
|---|---|---|---|
| R0 | 直读 ✓ | 直写（每单元 1 盘 ✓）| 无冗余 ⇒ 缺盘即离线 ✓ |
| R1 | **读均衡**：逐单元轮转副本 ✓（`rr[]` ✓）| **双写**（含重建中盘 ✓ `drv_wr_ok` ✓）| 单副本可读可写 ✓ |
| R5 | 单元读；缺失 ⇒ 其余数据⊕P 重建 ✓ | **全条带**（P=⊕新数据 ✓ 零旧读 ✓）或 **RMW**（P'=P⊕D_old⊕D_new ✓）；素材**先备齐再动盘** ✓（无半写 ✗）| 1 缺可读 ✓；降级写只动在线盘 ✓ |
| R6 | 单缺：P（P 缺则 Q+系数反解 ✓）；**双缺：2×2 GF 解** ✓ | 全条带：P=⊕D ✓ Q=⊕g_k·D_k ✓；RMW：Q'=Q⊕g_i·Δ ✓（**3 读 3 写** ✓）| 双缺可读 ✓；降级写（校验盘缺）不支持 ✗（扩展点）|
| R10 | 同 R1（按对 ✓）| 对内双写 ✓ | 每对容 1 ✓ |

- **GF(2⁸)**：多项式 **0x11D** ✓、`g_i = 2^i` ✓（与 arch §4.13 的 64KB LUT 同函数 ✓ ⇒ RTL 对拍锚点 ✓）。
- 写洞日志：写校验前记 `{vol,stripe}` ✓ 完成即清 ✓ 环满丢弃 ✓（简化 ✓）；`journal_replay` 幂等 ✓。
- 重建：**逐盘分轮**（扫完一轮仍有余盘 ⇒ `rb_scan` 归零续建 ✓）、**单盘扫毕才 ONLINE** ✓；
  重建读窗口把**全部 REBUILDING 盘视为不可读** ✓（内容未建全 ✗ 必走重建 ✓）；
  校验盘重建要求数据盘全在线 ✓ 否则**推迟**（返回 false ✓ 下轮重试 ✓）；镜像 = 兄弟副本拷贝 ✓。

## 5. 卷状态机（arch §4.13 ✓）

```
OFFLINE → INITIALIZING → ONLINE ⇄ DEGRADED → REBUILDING → ONLINE
                                   │
                                   └──（超冗余）→ OFFLINE ✓
```

## 7. 与现工程复用边界（内部开发计划 §1 ✓）

- **帧/命令口径不改** ✓：CDB@36 / tag@16-17 / LUN@24-31 全沿用（联合台逐字复证 ✓）。
- 成员 I/O 走 `DQ 64B 条目 → HBA 取指 → SSP COMMAND/DATA/RESPONSE → CQE` ✓（同 `tb_pair_bringup` ✓）。
- HDD 侧复用 `sas_hdd/tlm`（本轮为其**补齐写数据落盘** ✓ 见对拍报告 §3）；HBA 侧复用 `sas_hba/tlm`
  （本轮修其 **tx 缓冲在发覆写** ✗ 见对拍报告 §3）。

## 8. 驱动兼容（定案 ✓ 内部开发计划 §0）

**`hisi_sas` v3 零改动** ✓：Guest 见 1 块虚拟盘（元命令由 RAID 层本地应答、字节级沿用 HDD 侧 ✓；
数据命令条带化 ✓）；成员盘不可见 ✓；**无** MPI/MFI 消息层 / 无用户态管理工具 ✗（⛔ 对照
`mpt3sas`/`megaraid_sas` = 固件型 RAID 卡 ✗ 见内部开发计划 §0b ✓）。

## 9. ⛔ 明写简化（本轮不做；防"看着全绿其实缺件" ✗）

1. 无固件 / 无管理命令通道（卷表走寄存器 ✓ 留扩展点）；
2. R6 降级写（P 或 Q 盘缺）不支持 ✗；R5 P 盘缺时降级写不写校验（重建补 ✓）；
3. 无 DDR4 缓存控制器 / 无 MIG 时序 / 无 PHY；
4. STP（SATA）/ SMP（扩展器）/ TASK(TMF) 帧：接口留位 ✗；
5. 重建**限速/优先级**为计数级建模 ✗（`rb_scan` = checkpoint ✓）；日志环满 = 丢弃 ✓；
6. 性能指标（9.6GB/s XOR 等）为架构目标 ✗ 均不承诺时序收敛。
