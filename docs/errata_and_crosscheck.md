## 1. 条带翻译 vs spec 五式（M1 ✓ 6/6）

| 项 | 信源 A（spec）| 信源 B（TB 独立参照式）| 信源 C（手算）| 结果 |
|---|---|---|---|---|
| 例题输入 LBA=0x1000 / 4 盘 / 64KB | 公式 ✓（**例题行算术 ✗**）| 逐 LBA 全枚举 ✓ | 10 / 131072 / D2 / P=1 / LBA_m=1280 ✓ | **三者一致 ✓** |

- **⚠ spec 勘误（文档侧 ✗）**：`规格文档:957-961` 例题行写 `(0x1000×512)/(65536×3) = 0` ✗、
  `0x200000 % (65536×3) = 0` ✗ —— 实算 = **10** 与 **131,072** ✓。**公式本身正确 ✓**，
  实现与判据一律以**公式 + 手算**为准 ✓；建议 spec 修订该例题行 ✓。
- 衍生口径（实踩 ✗）：N=4 / 64KB ⇒ 行 = **384 块** ✓（非 1024 ✗）；左非对称 P 位 =
  `(n-1)-(stripe%n)` ✓（stripe0..3 ⇒ 3,2,1,0 ✓）；R6 双校验错开 `p1=(n-2)-((stripe+1)%n)` ✓。

### 2.1 R6 Q 盘旋转：**无符号下溢潜伏缺陷** ✗→✓（2026-10-09 推 RTL 时逮到 ✓）

- 旧式 `pQ = (n-2) - ((stripe+1)%n)` 在 `(stripe+1)%n == n-1` 时下溢 ✗（n=6, stripe=4 ⇒ −1 ✗）；
  旧 D 组只测 stripe 0/1 ⇒ **未暴露** ✗（RTL 侧逐条带推演时发现 ✓）。
- 修 = **取模回绕** ✓：`pQ = ((n-2) + n - ((stripe+1)%n)) % n` ⇒ 模式 = "**Q 落后 P 两格**" ✓
  （stripe0..5 ⇒ (P,Q) = (5,3)(4,2)(3,1)(2,0)(1,5)(0,4) ✓ 每盘每 6 条带恰得 1 次 Q ✓ P≠Q 恒成立 ✓）。
- 新增 **D9 存储级金标** ✓：stripe4/5 逐盘对照（含 Q 用 exp/log 独立乘法 ✓）⇒ 旋转被钉死 ✓。

### 3.1 联合台逼出的两侧真缺陷（✗→✓ 已回灌并复验 ✓）

1. **HBA TLM：tx 缓冲在发被覆写** ✗ —— 帧从 `tx_dw` **流式发送**，`H_WRDATA` 旧口径只等
   `txq` 空（命令帧一开始发即被摘出 ✗）⇒ 写路径在发期间覆写 `tx_dw` ⇒ 命令帧尾部被 DATA 帧
   内容冲掉 ⇒ HDD 收到"**COMMAND 帧型 + 数据内容**"混帧 ✗（探针实证：HDD opcode=0x5A =
   数据页图案 ✗）。修 = `H_WRDATA`/`H_ISSUE` 守卫改 **`!txq.empty() || tx_active`** ✓。
   **读路径无背靠背帧** ⇒ 此前 45 判据从未暴露 ✗（此条正是"联合台"的价值 ✓）。
2. **HDD TLM：WRITE 不落盘** ✗ —— 旧口径"立即 GOOD、不消费 DATA-out"（明写简化 ✗）⇒
   成员写全部丢失 ✗。修 = 写数据收集（`wr_active` ✓ DataOffset 落盘 ✓ **收满再 GOOD** ✓
   越界 ⇒ CHECK CONDITION ✓）；`S_EXEC` 空队列回 S_IDLE ✓（旧口径空队列卡 S_TX ✗ 一并修 ✓）。
