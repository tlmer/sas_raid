## 2. 判据口径十条（与全工程一致 ✓）

1. 期望值**必须带出处**（spec 公式 / arch / RTL 真值 / 独立参考公式 ✓）；
2. 参考模型**另写一遍**（TB 内独立实现 ✓：`RefRaid/RefR5/RefR6` + 独立 GF ✓ 防"同错"✗）；
3. 金标 = 第三信源，**也必须过算式复核** ✓（A5 实踩：金标 `drive_lba` 曾写错 ✗）；
4. 写惩罚/访问模式用**后端逐盘计数**佐证 ✓（读 D_old/P/Q、写 D/P/Q 的签名 ✓）；
5. 恒等式独立复核 ✓：R5 `⊕D⊕P≡0` ✓；R6 `P=⊕D` 与 `Q=⊕g_k·D_k`（**不同算法** = exp/log 表 ✓）；
6. 降级/重建的**判据在存储级** ✓（联合台经 `hdd.lba_ptr` 直读真存储 ✓ 不只看回读 ✓）；
7. 负控必列 ✓：超冗余 ⇒ OFFLINE ⇒ 读写皆拒 ✓（R5 2 缺 / R1/R10 全拔 / R6 3 缺 ✓）；
8. 帧级证据 ✓：拔盘期间**失败通道帧计数零增量** ✓（"没发帧"不靠推断 ✓）；
9. 账目闭合 ✓：`o_cqes == io_cnt == hdd.o_cmds_good` ✓、逐盘块账 `o_lba_read/write` ✓、
   零 `tag_mismatch` / 零 `cmds_err` / 零 link `dropped` ✓；
10. 联合台 per-I/O 自带上限（500k 拍 ✓）防挂死 ✓（**关** HBA 模型内 4096 拍响应超时 ✗
    —— 64KB = ~67 帧 > 4096 ⇒ 半途误报 ✗ 实踩 ✓）。

## 4. 缺陷与修复档案（本轮 9 条；全部由台逼出 ✓）

| # | 侧 | 症状 → 根因 → 修 | 捕获台 |
|---|---|---|---|
| 1 | 模型 | R1 读"固定取首副本" ✗ → `rr[]` 逐单元轮转 ✓ | r01-B5 |
| 2 | 模型 | 无全条带路径（只有 RMW ✗）→ 行对齐整行写 P=⊕新数据 ✓ 零读 ✓ | r5-C1/r6-D1 |
| 3 | 模型 | RMW 的 Q 缺会**半写** ✗ → 素材先备齐后动盘 ✓ | r5-C2/r6-D2 |
| 4 | 模型 | R6 降级读把"1 数据 + 1 校验缺"误判 2×2 拒 ✗ → **按本行失败数据盘数分类** ✓ | r6-D6/D7 |
| 5 | 模型 | `drv_ok` 含 REBUILDING ⇒ **重建读抄自身** ✗ → **读/写口径分裂** ✓ | rebuild-E3/E4 |
| 6 | 模型 | 多盘重建一把置 ONLINE ✗ / 写一块即 ONLINE ✗ → 逐盘分轮 + 单盘扫毕 ✓ | rebuild-E5 |
| 7 | 模型 | R1/R10 重建查表找不到 ✗ → 兄弟副本 `target^1` 拷贝 ✓ | rebuild（路径级 ✓）|
| 8 | **HBA TLM** | tx 缓冲**在发被覆写** ✗（命令帧 + DATA 背靠背 ✗）→ `!txq.empty()\|\|tx_active` 守卫 ✓ | array 探针 ✓ |
| 9 | **HDD TLM** | WRITE **不落盘** ✗（立即 GOOD）→ DATA-out 收集落盘、收满再 GOOD ✓；空队列卡 S_TX ✗ 一并修 ✓ | array A2/A5 ✓ |
